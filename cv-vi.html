Quy mô 1 (Dự án Full-Stack cá nhân)
Vị trí Fullstack Web Developer
Tổng quan Nền tảng quản lý công việc/project dạng Kanban lấy cảm hứng từ Trello (sản phẩm clone phục vụ học tập, không liên kết với Atlassian), kiến trúc tách rời Frontend/Backend trên MERN stack, dùng Socket.IO để cộng tác thời gian thực.
Công việc đảm nhiệm
  • - Thiết kế 41 REST API endpoints (/v1); triển khai SPA React/Vite trên Vercel và API Node.js/Express (REST + WebSocket) trên Render.
  • - Xây dựng kéo-thả multi-column & card mượt mà bằng @dnd-kit (custom collision detection, optimistic updates), quản lý state bằng Redux Toolkit, Redux Persist và Axios interceptors tự làm mới token (gom các 401 song song vào 1 lần refresh).
  • - Cài đặt đồng bộ theo phòng Socket.IO (board:<id>): presence trực tiếp, cập nhật card tức thì, bình luận và lời mời board cho mọi client đang kết nối.
  • - Xây dựng bảo mật Dual-Auth (HttpOnly Cookies + dự phòng Bearer Header cho trình duyệt chặn cookie) với JWT Refresh Token Rotation (token dùng 1 lần, tái sử dụng là thu hồi toàn bộ phiên), Google OAuth 2.0, kích hoạt email qua Brevo, rate limiting theo IP.
  • - Thiết kế tầng dữ liệu MongoDB với transaction đa document và Aggregation Pipelines gộp lời mời board cùng cảnh báo hạn chót DUE SOON / OVERDUE; upload media qua Cloudinary.
  • - Áp dụng validation Joi, tài liệu Swagger/OpenAPI (/v1/docs), viết 43 test unit & integration (node --test — gồm cả suite IDOR và rotation) chạy trên GitHub Actions CI.
Công nghệ

- Frontend: React 18, Vite, Material UI (MUI v5), Redux Toolkit, Redux Persist, @dnd-kit, Axios, Socket.IO Client.

- Backend & Cloud: Node.js, Express.js, MongoDB (Native Driver), Socket.IO, Joi, JWT, Google OAuth 2.0, Cloudinary, Brevo, Swagger, GitHub Actions.
